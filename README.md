# MiniCraft

A small browser-based Minecraft-inspired sandbox game.

## How to play

1. Open `index.html` in a browser, or run a local web server from this folder.
2. Use `A` / `D` or arrow keys to move.
3. Press `Space` to jump.
4. Left-click to place the selected block.
5. Right-click to break a block.
6. Use `Q` / `E` or the buttons below the canvas to cycle block types.

## Run locally

```bash
cd /workspaces/CCA-starter
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
